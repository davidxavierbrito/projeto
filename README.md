# Google Login Page - Binance

Uma réplica responsiva e pixel-perfect da interface de login do Google para Binance.

## 📋 Descrição

Este projeto recria fielmente a interface de login do Google/Binance com HTML e CSS puro, mantendo total fidelidade ao design original e responsividade completa.

## 🎨 Características

- **Design Dark Mode**: Interface escura moderna e elegante
- **100% Responsivo**: Adaptável a todos os tamanhos de tela (desktop, tablet e mobile)
- **Sem Dependências**: HTML e CSS puro, sem frameworks
- **Funcionalidade de Mostrar Senha**: Toggle para visualizar/ocultar senha
- **SVG Icons**: Ícones vetoriais do Google e logo da Binance
- **Acessibilidade**: Estrutura semântica e labels apropriados

## 🚀 Como Usar

1. Clone ou baixe os arquivos
2. Abra o arquivo `index.html` em qualquer navegador moderno
3. A página está pronta para uso!

## 📱 Responsividade

O layout se adapta automaticamente para:

- **Desktop** (>968px): Layout de duas colunas
- **Tablet** (640px - 968px): Layout em coluna única centralizado
- **Mobile** (<640px): Layout otimizado para telas pequenas com botões em pilha
